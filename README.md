# MCP2515 Driver
A MCP2515 driver programmed in C language.
The platform and demo are using RP2040 and pico-sdk.
Cmake is used as a project management tool.

Gemini AI was used for the generation of register map and bit-field of MCP2515.
It saves lots of time for typing register map and detailed comments.
But must be careful about some subtle mistakes hide in code.
